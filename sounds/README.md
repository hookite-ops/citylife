## 아직 비어 있는 소리 (넣으면 바로 재생돼요)

아래 이름으로 mp3를 이 폴더에 넣고 `sounds.json` 목록에 이름을 추가하면 돼요.

- horn.mp3 — 경적
- rain.mp3 — 빗소리 (반복 재생)
- pour.mp3 · water.mp3 — 물 붓기 · 수돗물
- microwave.mp3 — 전자레인지 (돌아감)
- kettle.mp3 · boil.mp3 — 전기포트 · 물 끓음
- sizzle.mp3 — 지글지글
- gas_on.mp3 · gas_off.mp3 — 가스불
- eat.mp3 — 먹기
- snore.mp3 — 잠자기
- alarm.mp3 — 알람
- truck.mp3 · mop.mp3 · spill.mp3 — 물류 트럭 · 걸레질 · 음료 쏟음
